# SystemVerilog RTL Module Library

A collection of reusable, parameterized SystemVerilog RTL modules for
digital design, FPGA development, and hardware verification.

## Overview

This repository contains synthesizable SystemVerilog implementations of
common digital-design building blocks. Modules are designed to be reusable,
parameterized where appropriate, and verified through simulation.

The library currently includes:

- Counters
- FSMs
- UART transmitter and receiver
- D registers/Shift registers
